# RestedRealm Collector agents

Read [docs/PROJECT-HANDOFF.md](docs/PROJECT-HANDOFF.md) before changing the addon, companion, upload contract or website integration. This repository contains the public source for the Forever addon and Windows companion. The running website source is a separate Git repository on the VPS at `/opt/restedrealm`.

Keep gameplay observations, SavedVariables, the companion SQLite queue, credentials, backups and full NPC or quest prose out of Git. Do not copy device tokens into issues, logs, screenshots or reports. A player controls their client data, so an upload is a report, not proof of game truth. Retain build, context and field-specific source labels. Do not promote a whole quest page based on one observation.

The in-game addon must stay free, readable, free of advertisements and donation requests, and light on game performance. Review the official Blizzard policy links and the implementation notes in the handoff before publishing an addon update.
